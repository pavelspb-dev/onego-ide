# Onego IDE

Учебная среда разработки для компьютера **Onego-15VA**: ассемблер, эмулятор процессора, интерактивный курс и пошаговый отладчик в одном приложении.

![PyQt5](https://img.shields.io/badge/PyQt5-5.15%2B-green)
![License](https://img.shields.io/badge/license-MIT-orange)
![Platform](https://img.shields.io/badge/platform-Linux-lightgrey)

---

## ✨ Возможности

- **Редактор кода** с подсветкой синтаксиса ассемблера Onego-15VA
- **Эмулятор процессора** с 16 регистрами, АЛУ, ОЗУ, SSD, BIOS и клавиатурой
- **Пошаговый отладчик** (F6–F9) с просмотром регистров и логов после каждого шага
- **Интерактивный курс** из 11 уроков с автопроверкой заданий, подсказками и примерами
- **Прогресс пользователя** с достижениями, сохраняется между запусками
- **Тёмная тема** интерфейса, человекочитаемые адреса (`RAM-5000`, `SSD-42`)

## 📋 Требования

- Python **3.8** или новее
- PyQt5 **5.15** или новее

Установка зависимостей:

```bash
# Debian/Ubuntu
sudo apt install python3 python3-pyqt5

# Fedora/RHEL
sudo dnf install python3 python3-qt5

# Alt Linux
sudo apt-get install python3 python3-module-PyQt5

# Arch
sudo pacman -S python python-pyqt5
```

## 🚀 Быстрый старт

### Из исходников

```bash
git clone https://github.com/pavelspb-dev/onego-ide.git
cd onego-ide
python3 onegoide.py
```

### Сборка RPM-пакета (Alt Linux)

```bash
mkdir -p ~/RPM/SOURCES

mkdir -p onego-ide-1.0
cp *.py onego-ide.desktop onego-ide.png onego-ide-1.0/
tar -czf onego-ide-1.0.tar.gz onego-ide-1.0/

cp onego-ide-1.0.tar.gz onego-ide.desktop onego-ide.png ~/RPM/SOURCES/
cp onego-ide.spec ~/RPM/SPECS/

cd ~/RPM/SPECS
rpmbuild -ba onego-ide.spec
sudo apt-get install ~/RPM/RPMS/noarch/onego-ide-1.0-alt1.noarch.rpm
```

После установки приложение появится в меню (**Образование → Онего IDE**) и станет доступно как команда `onego-ide`.

## 🖥 Использование

### Горячие клавиши

| Клавиша | Действие |
|--------|---------|
| `F5`   | Запустить программу |
| `F6`   | Начать отладку (пошаговый режим) |
| `F7`   | Выполнить одну команду |
| `F8`   | Продолжить до конца |
| `F9`   | Остановить отладку |
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` | Новый / Открыть / Сохранить |

### Пример программы

```asm
-- Вывести «Привет!»
положи 'П' в р1
запиши р1 в р0
положи 'р' в р1
запиши р1 в р0
положи 'и' в р1
запиши р1 в р0
...
```

### Язык ассемблера

| Команда | Описание |
|--------|---------|
| `положи X в рN` | Загрузить число (0–255) или символ в регистр |
| `сложи рA и рB, результат положи в рC` | Сложение |
| `вычти рA из рB, результат положи в рC` | Вычитание (B − A) |
| `умножь рA на рB, результат положи в рC` | Умножение |
| `рA больше рB?` | Сравнение «больше» (результат в `лз`) |
| `рA равно рB?` | Сравнение «равно» |
| `если да, то` / `если нет, то` | Условный переход |
| `запиши рA в рB` | Запись в память (`рB` = адрес) |
| `прочитай из рA в рB` | Чтение из памяти |

**Специальные регистры:**
- `р0` — всегда равен нулю
- `аси` — адрес следующей инструкции
- `лз` — флаг последнего сравнения (истина/ложь)

## 💾 Хранение данных

IDE хранит пользовательские данные в каталоге:

```
~/.onego-ide/
├── progress.json      # прогресс по урокам
└── onegossd.img       # образ SSD (перезаписывается при каждом запуске)
```

Прогресс сохраняется автоматически после выполнения каждого задания. Чтобы сбросить курс — просто удалите `~/.onego-ide/progress.json`.

## 📚 Курс

Интерактивный курс охватывает:

1. **Архитектура Onego-15VA** — регистры, память, BIOS
2. **Команда «положи»** — загрузка чисел в регистры
3. **Вывод символа** — работа с портом вывода
4. **Вывод строки** — последовательный вывод
5. **Арифметика** — сложение, вычитание, умножение
6. **Сравнения** — флаг `лз`
7. **Условные переходы** — `если да / если нет`
8. **Циклы** — повторение действий
9. **Память** — чтение и запись в RAM
10. **Ввод с клавиатуры** — чтение символов
11. **Мини-калькулятор** — итоговый проект

Уроки с автопроверкой отмечаются зелёным при успешном выполнении. Уроки без автопроверки имеют кнопку «Готово».
